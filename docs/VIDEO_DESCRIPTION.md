## YouTube description draft

> Sauti is a voice and text banking assistant designed for people with low vision in Burundi. This Chrome demo shows one balance question answered with Gemini Nano on-device and with cloud Gemini through Firebase AI Logic. The app reads the balance from a typed banking tool and displays when an offline balance was last saved. Sauti can also draft a transfer so the user can review it and decide whether to send. The demo uses fictitious accounts and funds.
>
